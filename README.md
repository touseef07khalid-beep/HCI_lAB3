# 🔍 SYNAPSE·LENS: Epistemic Contrast & Dissonance Diagnostic Suite

> **"WCAG for Ideas."**  
> While traditional contrast tools measure the photonic difference between `#000000` and `#FFFFFF`, **SYNAPSE·LENS** measures the **rhetorical divergence, unstated axioms, and epistemic dissonance** between competing architectures, claims, and engineering dogmas.

---

## 🧭 Overview

In technical debates—such as *Microservices vs. Modular Monoliths*, *Post-Quantum Lattice vs. Classical ECC*, or *Autonomous LLM Agents vs. Formal Verification*—the loudest friction rarely comes from syntax. It stems from **invisible axioms**, **semantic drift**, and **unacknowledged failure boundaries**.

**SYNAPSE·LENS** inverts the classic optical contrast magnifier into an interactive browser-based dialectic laboratory. Moving the refractive loupe over written proposals refracts rhetorical claims through optical filters to expose hidden premises, stress boundaries, and omissions.

## ⚡ Core Features

### 1. Interactive Refractive Loupe
- **Free-Floating Inspection Glass:** Centered crosshairs, radial rings, and coordinate telemetry.
- **Configurable Optics:** Dynamic aperture resizing ($140\,\text{px} - 380\,\text{px}$), magnification zoom ($1.00\times - 2.20\times$), and coordinate freeze locking.
- **Focal Deconstruction:** Hovering over claims parses tokens in real time, translating marketing rhetoric into concrete technical risks.

| Filter | Optical Analogy | Epistemic Transformation |
| :--- | :--- | :--- |
| **1. UV Dark Matter** | Ultraviolet fluorescence | Blurs superficial jargon and illuminates **unstated premises** (e.g., zero-latency networks, perpetual node availability). |
| **2. Steel-Man Prism** | Chromatic refraction | Strips away sarcasm, hyperbole, and ad-hominem attacks, rendering the opponent's claim in its most rational, defensible form. |
| **3. Reductio Stress-Test** | Thermal stress testing | Magnifies the claim to $1000\times$ production scale, identifying where the architecture deadlocks or fails. |
| **4. Jargon Doppler Shift** | Redshift / Blueshift | Flags overloaded vocabulary (*"Deterministic"*, *"Eventual Consistency"*, *"Zero Coupling"*) that mean different things across disciplines. |
| **5. Blindspot Heatmap** | Infrared omission sensor | Highlights missing technical requirements (disaster recovery, partition tolerance, memory ceilings, cost profiles). |

## 🚀 Getting Started

### Prerequisites
None. The application is completely self-contained in a single portable file:
- Zero external runtime dependencies (no npm, no node, no build steps).
- Uses standard modern browser APIs (HTML5 Canvas, CSS Backdrop Filter, Web Audio API, and Tailwind CSS CDN).

### Quick Launch
1. Save the code as `synapse-lens.html`.
2. Open `synapse-lens.html` in any modern web browser (Chrome, Edge, Firefox, Brave, Safari).
3. Click anywhere or toggle **SONICS: ON** in the header to activate the Web Audio context.

---

## 🎮 How to Use

1. **Navigate the Corpus:** Select a preset debate using the **CORPUS** dropdown (e.g., *Microservices vs. Monoliths*, *Post-Quantum Cryptography*, or *Autonomous AI*).
2. **Move the Lens:** Move your mouse over highlighted words or paragraphs to inspect them in the focal loupe.
3. **Switch Filters:** Click any of the 5 filter buttons in the toolbar (`UV DARK MATTER`, `STEEL-MAN PRISM`, etc.) to view different dimensions of the argument.
4. **Inspect Focal Claims:** Check the lower **Focal Forensic Deconstruction** panel to see the actual operational reality behind each statement.
5. **Freeze the Loupe:** Click **FREEZE LENS** to lock the loupe in place for steady reading or screenshot capture.
6. **Ingest Your Own Claims:** Click **INGEST CUSTOM** in the top-right corner to paste in your own architecture decision records (ADRs), proposals, or blog posts.

## 📊 Telemetry Metrics Glossary

- **$D_{00}$ (Axiomatic Weight):** Degree to which the argument relies on unproven baseline assumptions.
